# ТВЕРЬ Social 3.0

Полноценный MVP городской социальной сети на Vite + Supabase.

## Возможности
- регистрация/вход через Supabase Auth;
- профиль: ник, имя, возраст, био, аватар;
- публикации с реальной загрузкой фото в Supabase Storage;
- лайки, комментарии, подписки;
- поиск людей и публикаций;
- профиль пользователя и лента подписок;
- редактирование профиля;
- удаление собственных публикаций;
- закладки;
- уведомления о лайках, комментариях и подписках;
- адаптивный интерфейс для телефона и ПК;
- никаких вымышленных постов и аккаунтов в коде.

## Supabase
1. Открой SQL Editor.
2. Запусти `supabase.sql` целиком.
3. В Authentication → Email оставь email/password для первого запуска. Подтверждение email можно отключить только для теста.
4. В Vercel добавь `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. После коммита GitHub Vercel соберёт сайт.
