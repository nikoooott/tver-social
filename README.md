# ТВЕРЬ Social 3.0

Реальный MVP социальной сети на Vite + Supabase.

## Возможности
- регистрация и вход через Supabase Auth
- профиль, возраст, никнейм, био и аватар
- реальные публикации из Supabase
- загрузка фотографий в Supabase Storage
- лайки
- комментарии
- подписки
- закладки
- уведомления
- поиск людей и публикаций
- удаление своих публикаций
- адаптивная версия для телефона и компьютера

## Запуск
1. В Supabase выполни `supabase.sql`.
2. В Vercel добавь:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. Сделай Redeploy.

В проекте нет встроенных demoPosts и придуманных пользователей: лента берётся из Supabase.
