# ТВЕРЬ Social 4.0

Визуальный и UX-полиш поверх существующей Supabase-основы.

## Что нового
- Instagram-подобная мобильная навигация с safe-area для iPhone/Android
- устойчивые SVG-иконки на iOS Safari, Android, macOS и Windows
- профиль с полноценной лентой собственных публикаций, медиа-сеткой и статистикой
- просмотры постов: уникальный авторизованный пользователь учитывается один раз
- просмотры отображаются в ленте и профиле
- улучшенный адаптив для MacBook, Windows, планшетов и смартфонов
- активные состояния навигации и micro-interactions

## Важно
Перед использованием новой статистики просмотров один раз выполни обновлённый `supabase.sql` в Supabase SQL Editor. Миграция не удаляет существующих пользователей и публикации.
